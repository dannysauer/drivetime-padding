# Evidence

Dated receipts that prove a claim made elsewhere in the docs, such as test output, a measured Apps Script runtime over the full observation range, a captured broker payload proving minimization, or a prototype spike's findings.

Name each receipt `YYYY-MM-DD-short-claim.<ext>`, using the date the evidence was captured. Receipts are never edited. When newer evidence replaces older evidence, add the new receipt beside the old one and update the page that cites it.

A receipt that proves a requirement names the requirement's ID, such as `REQ-PERF-005`, so the requirements page and the traceability matrix can cite it.

There are none yet. The first receipts expected are the Prototype Spike 1 and Spike 2 reports listed in [`../../open-questions.md`](../../open-questions.md).
